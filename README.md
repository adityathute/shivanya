# Shivanya

The main open-source platform for the Shivanya ecosystem.

## Purpose

Shivanya is the core platform that brings together applications, services, and shared infrastructure into one ecosystem.

The platform is designed to support independent applications while providing a consistent foundation for authentication, analytics, UI, APIs, AI, and other shared capabilities.

## Architecture

```text
                    Shivanya
                       │
        ┌──────────────┼──────────────┐
        │              │              │
   Applications     Services      Shared SDK
        │              │              │
        ▼              ▼              ▼
    Memory         AI / APIs       UI / Shell
    Expense
    ERP
    Syra
    Vault
    Team
    Partner
```

## Goals

- Modular applications
- Reusable infrastructure
- Consistent user experience
- Developer-friendly architecture
- Open-source development
- Independent application evolution
